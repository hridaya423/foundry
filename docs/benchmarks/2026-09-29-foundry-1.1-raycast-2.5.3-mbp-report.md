# Foundry 1.1.0 vs Raycast 2.5.3.0 — warmed MacBook Pro rerun

2026-09-29, 05:38–05:42 UTC. Raw JSON: `2026-09-29-foundry-1.1-raycast-2.5.3-mbp-forward.json`
(Foundry first), `2026-09-29-foundry-1.1-raycast-2.5.3-mbp-reverse.json` (Raycast first).

Machine: MacBook Pro, Apple M4 Pro, macOS 27.0, on AC power (`--require-ac`).
Runner: `scripts/benchmark-launchers.swift` compiled with `swiftc -O` (the `swift` interpreter
crashes on this toolchain), run detached so the session could not kill it:

```
benchmark-launchers --runs 30 --warmups 5 --memory-samples 15 --startup-wait 10 --settle 2 --require-ac --isolate [--reverse]
```

Both launchers were quit before each leg (`--isolate` refuses to run otherwise). Every leg completed
all 30 measured panel cycles for both apps.
