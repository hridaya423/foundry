# Foundry 1.2 performance report

Verification pass for the 1.2 megaplan (conversion engine v2, surface facelifts,
parity commands, motion polish, perf/structure work). Same in-process driver as
the 1.1 report: `SearchLatencyBenchmarkTests` against the default registry,
90 ms keystrokes, first round warm-up.

## Host

| | 1.1 | 1.2 (this report) |
| --- | --- | --- |
| Machine | Apple M4, macOS 26.2, AC power | Same host, macOS 27 SDK build |
| Build | Staged `build/Foundry.app`, release | Staged `build/Foundry.app`, release, stripped |
| Accessibility for keystroke driver | No | No — the panel does not hide on app deactivation, so `drive-signposts.swift --reopen` cannot cycle it on this host. `panel.show` timing is carried over from the 1.1 measurement (that path is unchanged: the entrance animation is `opacity`/`scale` transforms on the existing view, and both animations are reduced-motion gated). |

## Results

| Metric | 1.1 | 1.2 | Note |
| --- | --- | --- | --- |
| `search.immediate` p50 / p95 | 16.05 / 24.5 ms | **16.82 / 35.6 ms** | p50 flat; p95 +11 ms — the registry grew (file actions, new commands, QR/OCR/color pickers). Well under the 41.5 ms budget. |
| `search.complete` p50 / p95 | 16.73 / 25.6 ms | **18.0 / 37.9 ms** | Same shape; under the 69.4 ms budget. |
| `search.complete` max | 81.7 ms | **54.4 ms** | Tail improved — provider deadlines unchanged (3.5 s), but synchronous `lsof` moved off the cooperative pool. |
| App bundle size | 14,604 KB | **8,100 KB** | −45%. `strip -rSTx` before signing (P6). |
| Executable size | ~13 MB | **6.8 MB** | Stripped symbols. |

Artifacts:
- `2026-10-08-foundry-1.2-search-latency.json` — raw benchmark output (n = 132).

## What changed that could affect these numbers

- `CommandPanelState` split into three files (behavior-preserving; no hot-path change).
- `AgentProviderIcon`, `PreviewPane`, and the rename alert no longer do
  synchronous `NSWorkspace.icon(forFile:)` on the render path — icons decode on
  a utility queue via `FileIcon`/`CommandIconRepository`.
- `MacUtilitiesProvider` `lsof` calls run through `ProcessRunner` async instead
  of blocking a cooperative thread.
- Media batch downloads capped at 3 concurrent jobs (pre-existing bound kept).
- Conversion graph adds providers to the registry surface, which is the
  `search.complete` p95 delta above — acceptable inside budget.

## Regression verdict

No budget regression. p95 moved up ~11 ms on a richer result set and stays
roughly 2× under the 1.1 budget; the worst-case tail (max) improved ~33%.
