# Foundry 1.3.0

Foundry 1.3 is a finishing release. It removes features that did not earn their place. Every surface now uses the same keys, the same rows and the same feedback.

## Removed

- **Camera is gone.** The Camera mode, its command and its capture service are removed. Foundry no longer asks for camera access, and the app carries no camera entitlement.
- **Settings › Appearance is gone.** Panel contrast is now in Settings › General.
- **Settings › Agents no longer lists sessions.** The Agents shelf shows them.

## Brand

- **New app icon.** The icon is the Split Mould mark, generated by `scripts/render-icon.swift`.
- **Chalk DMG.** The installer background is chalk with an orange full stop, as a multi-resolution TIFF.
- **Menu bar glyph.** The menu bar shows the mark as a template image.
- `build-app.sh` prefers the Developer ID identity when it signs.

## Setup

- Setup has four steps: welcome, shortcut, bring your snippets, done.
- You try the shortcut during setup. The step completes only when a real launch works.
- Foundry takes ⌘ Space only when you choose "Take ⌘ Space". The other answer is ⌥ Space.
- Foundry imports snippets from Alfred directly and from a Raycast export file.
- Paste, snippet insert, window tiling and screen text capture ask for permission in the panel before they act.

## The panel

- Esc clears the query first and closes the panel second.
- Closing the panel returns focus to the app you were using.
- Confirmations for Empty Trash, trusting a script folder, renaming a file, the colour format, Wi-Fi QR codes, saving a QR code, the Firefox connector and download notices open inside the panel, not in an alert window.
- Space or ⌘Y opens the system Quick Look panel for a file result. The arrow keys keep moving the selection and the preview follows. Esc closes the preview first.
- Image results offer Preview Extracted Text, which shows the recognised text in Quick Look.
- Reduce Transparency no longer draws a black wash. Increase Contrast draws a visible border.

- Foundry reopens where you left it. It returns to Home after the time you set in Settings › General.
- ⌘1 to ⌘8 open your favorites. Hold ⌘ to see the numbers.
- ⌃N and ⌃P move the selection. ⌘↑ and ⌘↓ jump to the ends of the list.
- Every footer shows the keys that work on that screen.
- VoiceOver announces the selected row and its shortcut.
- A copy confirms itself after the panel closes.

## Search

- **Time zones.** Type "now in sf" or "12pm est" in root search. Foundry shows the time with the zone abbreviation in effect on that date.
- One score orders results, so a weak app match no longer outranks a stronger command match. Built-in aliases rank as aliases.
- File search runs inside the app, not through one `mdfind` process per keystroke.
- Apps on external volumes and in custom folders appear in search. New installs appear without waiting for a rescan.
- Search does less work per keystroke.

## Convert

- **Options.** Strip metadata and a name template with `{name}`, `{date}` and `{ext}`.
- Images convert to one PDF.
- Files that you drop on the panel offer Shelf, Convert, Extract Text and Compress. File results have a Share action.
- Batches that use ffmpeg, ImageMagick, pandoc or soffice run two conversions at a time.

## New commands

- Capture Text from Screen, Wi-Fi QR Code, Empty Trash and Toggle Desktop Icons.
- The colour picker offers Hex, RGB, RGBA, HSL, HSV, OKLCH and NSColor, keeps 12 recent colours and shows WCAG contrast against white and black.

## Each surface

- **Clipboard.** Option-Return pastes plain text. Filter chips show counts. Pause shows a notice with Resume. ⌘K offers Copy Merged with Previous for two text items.
- **Snippets.** Tag filter chips, sort modes and CSV export. A snippet result has a preview pane, and a setting chooses whether Return inserts or copies. The editor focuses the title of a new snippet. A duplicate keyword shows a warning with the clash. The editor can use a monospaced font.
- **Quick AI.** Empty chats are not saved. The model menu changes only the current chat.
- **File Shelf.** ⌘A selects all files. Space opens Quick Look.
- **Drop.** Files that you drop on the panel offer Add to File Shelf, Convert, Extract Text and Compress. Arrow keys and Return choose.
- **Downloads.** The header is the link field. Arrow keys select a download. Return downloads the links, or opens the selected file. ⌘⌫ removes a finished row. ⌘K holds the folder actions.
- **Translator.** Detect Language is the default source. Foundry remembers your language pair.
- **Emoji.** Return pastes the emoji. Recent emoji show your skin tone.
- **Developer Tools.** One row of tool chips. Long values truncate in the middle.
- **Calculator.** Arithmetic shows "=". Unit conversions show "→".
- **Agents.** Tabs show only the providers that have sessions. Arrow keys select a session, and Return opens it.

## Settings

- Settings is a resizable window, 820 × 600 at first and 680 × 480 at the smallest. The panel's comma key, the status item, the panel menu and the app menu open it.
- Reset and Import apply at once. Foundry no longer quits to apply them.
- The sidebar is a standard macOS sidebar. The window remembers its size, position and last pane.
- The shortcut recorder takes Space or Return to record, Esc to cancel and Delete to clear.
- Text fields save when you leave them.
- When you remove a quicklink, Foundry offers Undo.

## Under the hood

- The Home clipboard widget no longer reads the pasteboard every 10 seconds.
- The clipboard is read only while the panel is open. Writes to the store change only the rows that differ.
- Window tiling keeps the frame a window settles at. It no longer reverts apps that resize with an animation.
- ChatGPT sign-in is labelled "unofficial", is off by default and cannot be enabled without opting in.
- Settings text carries localization resources, and `lint-l10n.sh` checks status and error strings.
- Every radius, height, opacity and status colour comes from one token file. A lint rule blocks new literals.
- Tests no longer write to your ranking history in `~/.local/share/foundry/usage.json`.
