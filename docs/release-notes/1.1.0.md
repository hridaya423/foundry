# Foundry 1.1.0

Foundry 1.1 adds the launcher features people expect from Raycast, a guided first run, a Settings window of its own, and a round of polish on every existing feature. The panel also opens faster and uses less memory than 1.0.

## First run and everyday use

- **Guided onboarding.** A seven-step welcome window covers your shortcut, a first try, preferences, optional permissions, and AI setup. You can skip any step. If you quit partway through, it picks up where you left off, and you can reopen it any time from Welcome Guide.
- **⌥Space is the new default shortcut** on new installs. Onboarding can switch you to ⌘Space and shows how to free that shortcut from Spotlight. If the shortcut fails to register, Foundry now tells you and offers to pick another one.
- **Menu bar item** with Open Foundry, Clipboard History, Pause Clipboard, Settings, Welcome Guide, and Quit. You can hide it in Settings.
- **No more launch dialogs.** The "Launch at login?" and "What is your main browser?" prompts are gone; both settings now live in onboarding and Settings. The browser prompt no longer comes back on every launch.
- **Pop to root.** Reopen the panel within 90 seconds and you're back where you left off. You can change the timeout in Settings.
- **Compact mode** shows only the search bar until you start typing.

## Launcher

- **Redesigned Home** with favorites, recent items, and window layouts. Helper apps no longer appear as suggestions.
- **Sectioned results.** A Top Hit comes first, then the other results grouped by kind. Rows show alias and hotkey badges and a dot for running apps.
- **Searchable ⌘K.** The Actions panel floats as a card over the result list with its own filter, and each action shows its shortcut. ⌘↵ (second action), ⇧⌘C (copy), ⇧⌘F (reveal in Finder), ⌘D (favorite), ⌘⇧, (configure a command's hotkey and alias), and ⌃X (delete your own quicklinks and snippets) work straight from the result list.
- **App search finds Finder, Safari, and other system apps**, and helper apps stay out of results.
- **One System Settings entry** replaces more than 50 separate "Open X Settings" commands. Individual panes still appear when you search for them.
- **Quicklinks** with `{argument}`, `{clipboard}`, `{date}`, `{time}`, and `{selection}` placeholders. Six defaults are included, you can import your Raycast Quicklinks (including their per-link "open with" app), and each link can show its own favicon.
- **Script Commands** that follow Raycast's directive format. Foundry asks before running scripts from a folder for the first time.
- **Apple Shortcuts** can be listed and run from the launcher.
- **File search** with the `f ` prefix, powered by Spotlight — `kind:` filters (image, pdf, folder, …), a bare `f` shows this week's files, ⌘Y Quick Look, drag-out onto other apps, and a clear notice when Spotlight is disabled.
- **Preview pane** for Clipboard and file search.
- **Fallback commands** when nothing matches: Ask AI, Search Google, and Search Files.
- **34 window layouts**, including thirds, fourths, almost maximize, center half, and moving windows between displays.
- **Backup and import.** Export your settings, snippets, quicklinks, script folders, and ranking to a single file, and import it on another Mac. Secrets stay in your Keychain and are not included.

## Settings

- Settings now opens in its own resizable window (⌘,), with a search field that jumps straight to any setting.

## Feature polish

- **Clipboard history** now lives in a local SQLite database. Return pastes into the app you were using, ⌘↵ copies, ⇧↵ pastes as plain text, and ⌘P pins an item. ⌘1–5 filter by text, images, files, and links, and full-text search covers everything. Retention is configurable — 1,000 items, 1 GB, and 90 days by default, with pinned items exempt — and password managers and concealed types are never captured. Your 1.0 history is migrated automatically.
- **Quick AI** opens on an empty state with suggestions. Stopping a reply keeps the partial answer, each message has a Copy button, ⌘N starts a new chat, and ⌘. stops a reply.
- **Snippets:** Return inserts the snippet into the previous app, and ⌘↵ copies it.
- **Emoji** remembers what you use most.
- **Developer Tools:** ⌘1–7 switch between tools.
- **Calculator:** copy confirmations name the copied value, currency results show the date of the rate, and your last 10 copied answers come back on `calc`, `=`, or `calc history`.
- **Widgets** mark weather and stocks as offline when they're showing cached data. Storage says whether it shows free or used space.
- **Translator** gains a swap-languages button and clearer errors for missing language packs.
- **Agents** show a loading state and whether live updates are connected.
- **File conversion** explains which tool it needs and where to get it.
- Error messages now say what happened and what to do next. Actions that fail now always show a message.
- VoiceOver can activate result rows, actions, clipboard items, and File Shelf files. ⌘C, ⌘X, ⌘A, ⌘Z, and ⌘W now work in the Settings and onboarding windows.

## Performance

These numbers were measured on an M4. The 1.0 baseline was measured on an M4 Pro. Details are in `docs/benchmarks/2026-09-26-foundry-1.1-report.md`.

| | 1.0 | 1.1 |
| --- | --- | --- |
| Panel open (p50 / p95) | 19.5 / 29.2 ms | 13.6 / 20.9 ms |
| First open after launch | 209 ms | 20 ms |
| Search, first results (p95) | 68.5 ms | 40.0 ms |
| Memory after use | 50.2 MB | 31.2 MB |
| Idle wakeups with the panel hidden | clipboard checked every 0.7 s | 0.12 per second (checks every 5 s while you're away) |

## Requirements

macOS 14 or later.
