# Foundry 1.2.0

Foundry 1.2 turns the app into a converter, rounds out Raycast parity (OCR, color picker, QR, confetti), gives Downloads, Snippets, and Clipboard a full facelift, and ships the first branded build — custom icon, designed DMG, and an 8.1 MB app.

## Brand

- **Custom app icon.** The Split Mould mark is two chalk mould halves with one orange cast between them, on a dark ink squircle. `scripts/render-icon.swift` generates it, and it is bundled at every resolution.
- **Menu bar glyph.** The menu bar shows the same mark as a template image, so macOS tints it for light and dark menu bars.
- **Designed DMG.** `scripts/package-dmg.sh` now produces a branded installer: ember-bloom background art, "DRAG TO INSTALL" arrow, positioned app + Applications icons, and a custom volume icon. `verify-packaging.sh` asserts the icon and layout made it in.
- The app is **8.1 MB** (was 14.6 MB) — the release binary is stripped before signing.

## Convert anything

- **Conversion graph.** File conversion now routes through a graph of native and external engines — multi-hop conversions (up to 3 hops), native hops preferred, brew engines provisioned on demand with a fingerprinted setup plan.
- **Native engines, no installs:** ImageIO (png/jpg/heic/tiff/gif/bmp/jp2/avif, reads webp/SVG/camera RAW), PDFKit (pdf → image/text, merge/split), AVFoundation (mp4/mov/m4a/wav), plutil, csv ↔ json, zip/tar archives, Vision OCR.
- **External engines when needed:** ffmpeg (full media matrix incl. subtitles and opus), ImageMagick (webp write, ico/icns), pandoc (md/epub/docx/html), soffice (xlsx → csv and friends).
- **Conversion surface facelift:** drag files onto the panel, adjust quality/pages/DPI/bitrate per format, multi-select batches with per-item results and size deltas, and a "convert another" flow. Options are only shown when they apply.
- **Finder-grade file actions** on file results: Open, Reveal, Copy, Rename, Compress, Move to Trash, Add to File Shelf, Open With…, and Extract Text.
- **`--convert <path>`** launches the panel straight into conversion — scriptable, and wired for Finder "Open With".

## New commands

- **Extract Text (OCR)** — Vision text recognition on images, from the command palette or a file result's actions.
- **Pick Color** — `NSColorSampler` eyedropper, copies the hex to your clipboard.
- **Generate QR Code** / **Read QR Code** — CoreImage generation with a save dialog; Vision barcode reads on images.
- **Paste as Plain Text** — strips formatting anywhere.
- **Confetti** — celebrate a finished batch (also fires when onboarding completes).

## Snippets

- **Usage tracking** — `useCount` and `lastUsedAt`, shown in the list and used for ordering. Existing libraries decode cleanly.
- **Raycast-compatible export** — `foundry-snippets.json` round-trips with Raycast's format (import already worked).
- **Configurable expansion delimiters** — Space, Tab, Return, comma, period, colon, semicolon; set in Settings → Snippets.
- **Placeholder insertion** — an NSTextView-backed editor with an insert menu for `{date}`, `{time}`, `{clipboard}`, `{selection}`, `{cursor}`, and `{argument name}` at the cursor.
- **Import/Export buttons** live in the Snippets header.

## Downloads facelift

- Remote-host favicons, completed-file thumbnails, status badges, hover states, and a right-click context menu (Open, Reveal, Copy URL, Retry, Cancel, Remove). Progress, speed, ETA, and parallel-batch caps are unchanged.

## Clipboard

- **Paste as Plain Text** and a smart **Open Link** action when the clipboard holds a URL. Images and file payloads keep direct paste.

## Onboarding & motion

- The panel now fades and drifts in on open (reduced-motion aware).
- Onboarding steps reveal with a stagger, the try-it keycap pulses, the success check bounces, footer dots spring, and finishing fires confetti plus a haptic.
- The ember accent from the icon now carries through onboarding.

## Performance

- App bundle 14.6 MB → 8.1 MB.
- Agent/provider icons, file previews, and the rename-alert icon no longer hit `NSWorkspace` on the main actor — they load async through the shared icon cache.
- Port lookups (`lsof`) are now async, so provider deadlines actually bound them.
- `CommandPanelState` split into core + Settings + Modes (1,463 → 923/357/216 lines).

## Requirements

macOS 14 or later.
