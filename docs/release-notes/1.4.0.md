# Foundry 1.4.0

Foundry 1.4 checks for updates, puts answers above commands and fixes the problems that an audit of 1.3.0 found.

## Updates

- **Foundry checks for updates.** When GitHub has a newer version, Home shows a notice. Download opens the release page in your browser. Nothing downloads by itself.
- Foundry asks GitHub the first time you open the launcher after Foundry starts, then at most once a day. The request sends no identifier and not your version.
- To stop the check, turn off Check for updates in Settings › About.

## Answers first

- Times and unit conversions show the calculator's card, and answers rank above every command.
- Time queries accept extra words, such as "time in SF now", and convert one zone to another.
- Conversions take a target unit. Compound units and date maths work.
- `1,000 km` is 1000 km, `-2^2` is -4 and `100 + 10%` is 110.
- Foundry tries units before currencies. Only known currency codes reach the exchange rate service.
- Developer Tools read hex operands, seconds with thousands separators, ISO 8601 times with `Z` or an offset, and URL-safe or unpadded base64.

## Your data

- Restoring a backup reloads Home widgets and quicklinks before anything can save over the restore. A failed restore puts every file back.
- Backup import lists the shortcuts, AI endpoints and script folders that it will change. It refuses a global shortcut that has no modifier key.
- Foundry sets aside an unreadable snippet, quicklink or config file. It no longer writes defaults over it.
- When the config file fails to save, Settings shows the error.
- Clipboard history deletes the old plain-text archive, zeroes deleted rows and counts images toward the size limit.

## Security

- Foundry sends an API key only over HTTPS or to your own Mac. It does not follow a provider redirect that changes the scheme, the host or the port.
- Agent cards resume through a command that Foundry builds and quotes. Foundry never runs a command that arrives over the agent socket.
- Removing a script folder in Settings revokes its trust.
- Media downloads take the file extension from the file's bytes, not from the server.
- Diagnostic messages are private in the system log.

## Fixes

- Snippets expand as soon as you save them. `{cursor}` places the caret.
- A multi-page PDF converts to a folder of PNG or JPG pages. Strip Metadata applies the EXIF rotation first.
- Restart, Shut Down and Log Out ask before they act. Lock Screen works on current macOS. Flush DNS Cache asks for an administrator password.
- If another app holds a command's shortcut, only that command loses it, and Settings says so. The recorder refuses a shortcut that another command uses.
- Foundry remembers which launchers it moved off ⌘ Space, and Settings › General can give ⌘ Space back to them.
- Closing the launcher while Settings is open hides only the launcher.
- Clipboard History shows copied images. A copied web link is saved as a link, not as a file.
- Window tiling works after the first permission prompt, without a relaunch.
- The Firefox connector starts when Firefox launches it and reconnects after Foundry restarts.
- Browser results no longer show `<null>` titles. Firefox shows only the tabs of its current session.
- Notes search reads every note in three Apple events. When Notes is slow, Foundry says so.
- A command that times out stops with all of its child processes.
- AI answers skip a stream line that is not JSON, run parallel tool calls separately and show a provider error as an error.
- Settings is an opaque window with Foundry's own sidebar. It reopens on the last pane.
- Settings can remove an agent bridge. It removes only Foundry's hooks.
- Home no longer shows daily tips.

## Speed

- An app index update starts the reload at once, so the next keystroke rarely waits.
- Snippet search prepares snippets once per file change. With 2,000 snippets in a debug build, a keystroke took 190 ms instead of 395 ms.
- The emoji picker builds its list once and loads its catalogue off the main thread.
